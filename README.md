# 🐉✨ script_copiar_colunas: O Mágico das Planilhas! ✨📊

**Um facilitador de copiar dados de uma coluna para outra!**  
*Feito com ❤️, pandas 🐼 e um pouco de chá ☕.*

---

## 🚀 O Que Isso Faz?

Este script é como um **assistente mágico** para lidar com Excel! Ele:
- Copia colunas específicas de um arquivo para outro 🧙♂️
- Aplica filtros para pegar só o que importa 🎯
- Multiplica valores (se você quiser brincar de matemágica!) ✖️
- **Salva automaticamente** e até evita sobrescrever arquivos existentes (que bonzinho! 🙌)

---

## 🎩 Funcionalidades Mágicas

- **Seleção de Colunas Inteligente** 🧠: Mapeie colunas de origem para destino como um chef!
- **Filtros Poderosos** 🔍: Filtre dados como um caçador de tesouros!
- **Multiplicação Mística** 🔢: Transforme números com um fator secreto!
- **Auto-Salvamento Seguro** 💾: Cria versões novas pra não bagunçar o original!
- **Tratamento de Erros** 🛡️: Avisa se algo der errado (ele é bem educado!) 

---
